# Figures

This directory contains figures and cartographic products generated from the Kano groundwater stress analysis.

## Final map

The principal figure is:

`Kano_Groundwater_Stress_Change_2024_2025`

This map shows the spatial change in combined groundwater stress across the 44 Local Government Areas (LGAs) of Kano State between 2024 and 2025.

## Map design

The map includes:

- Kano State boundary
- LGA boundaries
- Groundwater stress-change classification
- Five-class diverging colour scheme
- Legend
- North arrow
- Scale bar
- Data source note

The colour scheme progresses from:

**Blue → White → Red**

where blue represents decreasing stress and red represents increasing stress.

Additional figures, including charts summarizing LGA-level stress changes, may be added as the project documentation is developed.
