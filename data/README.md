# Data

This directory contains documentation and, where permitted, links or instructions for obtaining the datasets used in the Kano groundwater stress analysis.

Raw source datasets are not included unless their licensing and distribution terms permit redistribution.

## Main data sources

- Sentinel-2 imagery — vegetation/NDVI analysis
- CHIRPS precipitation data — rainfall analysis
- GADM administrative boundaries — Kano State and LGA boundaries

See the main project README for the complete methodology and processing workflow.
