# Scripts

This directory contains scripts used to process, analyze, and summarize the datasets for the Kano groundwater stress project.

The workflow includes:

- Sentinel-2 NDVI processing
- Annual NDVI calculation
- CHIRPS annual rainfall processing
- Vegetation stress calculation
- Rainfall stress calculation
- Combined groundwater stress calculation
- 2024–2025 stress-change calculation
- LGA-level zonal analysis
- Generation of final analysis outputs

Scripts will be added after the computational workflow has been organized and verified for reproducibility.
