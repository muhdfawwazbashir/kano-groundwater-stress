# Outputs

This directory contains the final outputs generated from the Kano groundwater stress analysis.

## Main outputs

### LGA-level stress results

`Kano_LGA_Stress_Results`

Contains the mean groundwater stress for each of the 44 Kano State LGAs for:

- 2024
- 2025
- Change between 2024 and 2025

The change field is calculated as:

`stress25 − stress24`

### Final map

`Kano_Groundwater_Stress_Change_2024_2025.pdf`

The final cartographic representation of groundwater stress change across Kano State.

## Classification

The stress-change map uses five classes:

| Class | Change range |
|---|---:|
| Strong decrease | -0.028 to -0.001 |
| Moderate decrease | -0.001 to 0.026 |
| Little/no change | 0.026 to 0.053 |
| Moderate increase | 0.053 to 0.080 |
| Strong increase | 0.080 to 0.107 |

A blue–white–red diverging colour scheme is used, with blue representing decreases and red representing increases.

Large raster and GIS files may not be included directly in this repository. Their availability and reproducibility instructions will be documented separately.
