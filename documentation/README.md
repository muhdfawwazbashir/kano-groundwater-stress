# Documentation

This directory contains detailed documentation for the Kano groundwater stress analysis.

## Project documentation

The documentation will describe:

- Study area and research context
- Data sources
- Data preparation
- NDVI processing
- Vegetation stress calculation
- CHIRPS rainfall processing
- Rainfall stress calculation
- Combined groundwater stress methodology
- 2024–2025 stress-change analysis
- LGA-level analysis
- Classification of stress change
- Results and interpretation
- Cartographic production
- Limitations and recommendations

## Reproducibility

The project is being documented to make the analytical workflow transparent and reproducible.

Where source data cannot legally or practically be redistributed, documentation will provide information on the original data source and instructions for obtaining the required datasets.

## Final report

A formal report documenting the completed analysis will be added to this directory after the project workflow and results have been fully documented and verified.
